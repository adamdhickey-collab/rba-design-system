Using an icon

RuleRequirement
ColorThe file has no color of its own — it inherits. Set color on the element and the icon follows, which is why the same file works in light and dark.
SizeDrawn on a 24×24 grid. Use it at 16, 20, 24, 32 or 40px. Off-grid sizes blur the strokes.
Pairing with textAlign to the text's optical centre, not its baseline, and keep 8px between glyph and label.
AccessibilityAn icon alone on a control is not a label. Give the control real text or an aria-label; mark decorative icons aria-hidden="true".
NeverRecolor parts of a single icon, add a second icon family alongside these, rotate or mirror to invent a new meaning, or apply effects.
