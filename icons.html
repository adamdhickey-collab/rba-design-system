Using an icon

RuleRequirement
Which formatSVG unless something refuses it. It stays sharp at any size and takes color from whatever it sits in. The PNG is 267×267 on transparency, drawn in near-black — reach for it only where SVG won't go, and remember it will disappear on a dark background.
ColorThe SVG carries a near-black stroke, but on this site it is painted through a CSS mask so it follows the theme. In your own page, either recolor the stroke or mask it the same way — background: currentColor with mask: url(icon.svg). That is what makes one file work in light and dark.
SizeDrawn on a 64×64 grid at a 2px stroke. Use it at 24px and up; below about 20px the strokes close in on each other and the detail turns to mud.
WeightEvery icon in the set is the same outline weight. Don't mix in a filled or duotone icon from elsewhere — one odd weight on a slide is more noticeable than a missing icon.
Pairing with textAlign to the text's optical centre, not its baseline, and keep 8px between glyph and label.
AccessibilityAn icon alone on a control is not a label. Give the control real text or an aria-label; mark decorative icons aria-hidden="true".
NeverRecolor parts of a single icon, rotate or mirror one to invent a new meaning, or apply effects.
